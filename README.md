Shadow Protocol is a 2D top-down stealth game: sneak past patrolling guards and their vision cones, hide in shadow zones, manage your noise, steal every intel chip, and slip out through the exit across 3 handcrafted levels.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
# 然后在浏览器打开 out/index.html
```
